# 活断層くん（全国 活断層マップ）

都道府県を選ぶと、その都道府県の活断層と地震調査研究推進本部（地震本部）の長期評価（ランク・規模・30年以内の発生確率）を表示するスマホ向けアプリです。

- GitHub Pages でそのまま動きます（`index.html` ＋ `d3.min.js`・アイコン・`manifest.webmanifest`・`sw.js`）。
- Android の Chrome で開き、メニューの「ホーム画面に追加」でアプリとして使えます。一度開けば圏外でも使えます。
- 📍 現在地（スマホのGPS。移動に合わせて更新、もう一度押すと現在地へ戻る）、📏 距離計測（GRS80楕円体）、背景切替（標準・道路/鉄道/都市・白地図・夜間・航空写真・地理院地図 標準/淡色）。

## データの出典
- ランク・M・30年確率：地震調査研究推進本部「地震活動の特徴」各地方ページ（算定基準日 2026年1月1日）。近畿は「近畿地域の活断層の長期評価（第一版）」（2026年8月28日公表）を反映。
- 断層線：GEM Global Active Faults Database（CC BY-SA 4.0）。評価区間との対応づけは近似。
- 背景地図：Natural Earth（パブリックドメイン）。航空写真・地理院地図は国土地理院「地理院タイル」（出典：国土地理院）。
- 地図描画ライブラリ：D3.js（ISC License、`d3-LICENSE.txt`）。
